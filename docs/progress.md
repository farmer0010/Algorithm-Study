- Union-Find(분리집합) + MST(크루스칼) — 신규 도입 완료 (섬 연결하기)
- 그래프 단일 출발점 최단경로 (다익스트라, PriorityQueue + Lazy Deletion) — 신규 도입 완료 (배달)
- DP 2차원 격자형 (min(위, 왼쪽, 대각선) + 1 패턴) — 신규 도입 완료 (가장 큰 정사각형 찾기)
- 플로이드-워셜의 "관계 추론(도달 가능성)" 응용 — 신규 도입 완료 (순위)
- 다단계 문자열 규칙 순차 처리 (7단계형) — 재응용 완료, 왕복 0회 (신규 아이디 추천)
- 재귀(DFS) 기반 "포함/제외" 조합 생성 — 메뉴 리뉴얼 패턴 재응용 완료 (순위 검색)
- 해시맵 전처리 인덱싱 (등록 시점에 미리 다수 키로 펼쳐두기) — 신규 도입 완료 (순위 검색)
- 이진 탐색 lower-bound 응용 ("특정 값 이상 개수 세기") — 입국심사 패턴 재응용 완료 (순위 검색)
- BFS depth 관리 (Node+depth 묶음 방식) — 재응용 완료, 왕복 1회 (단어 변환)
- 모노토닉 스택 (Monotonic Stack) — 신규 도입 완료, 왕복 4~5회 (주식 가격)
- 백트래킹(DFS) 기반 조합 배정 + Set을 이용한 순서무관 중복 제거 — 신규 도입 완료, 왕복 1회 (불량 사용자)
- 재귀(Recursion) 기반 "믿음의 도약" (from/to/via 역할 교대) — 신규 도입 완료, 왕복 0회 (하노이의 탑)
- 트리 구성(좌표 기반 BST 삽입) + 전위/후위 순회 재귀 — 신규 도입 완료 (길 찾기 게임)
- 1차원 순수 재귀 (분할 후 위임 패턴, `cut(M,N)=N+cut(M-1,N)`) — 신규 도입 완료, 왕복 3회 (종이 자르기)
- 부모 체인 단방향 재귀 (트리형이지만 한 방향으로만 타고 올라가는 단순 구조) — 신규 도입 완료, 왕복 1회 (다단계 칫솔 판매)
- 백트래킹 + 1차원 압축 설계 (2차원 보드 대신 depth당 값 하나만 기록) — 재응용 완료, 왕복 2회 (N-Queen)

## 최근 취약 포인트 (누적 추적용)
- **"선언은 했지만 반환 흐름에 연결 안 됨" 패턴 (Day131에서도 재발했으나 개선 신호):** 종이 자르기에서 `cnt`를 채워놓고 다른 값을 리턴하던 실수가 또 나왔지만, 코치 지적 없이도 다음 시도에서 거의 바로 스스로 교정 — 완전히 사라지진 않았지만 자가 교정 속도가 빨라짐.
- **char 리터럴과 String 리터럴 혼동 (신규, Day131):** `'-'`(char)와 `"-"`(String)를 `.equals()`로 비교하며 항상 false가 나와 NPE 발생. `.equals()`는 String 객체끼리만 의미가 있다는 걸 실제 런타임 에러로 체득.
- **배열 인덱스와 저장값의 역할 혼동 (신규 관찰, Day131):** N-Queen에서 `g_col[row] = col`과 `g_col[col] = row`를 헷갈림 — "이 배열을 나중에 조회할 때 어떤 규칙으로 읽을 것인가"를 먼저 정하고 그 규칙에 맞춰 저장해야 함을 스스로 교정.
- **빈 컬렉션에서 peek()/pop() 호출 순서 실수 (Day129):** `!stack.isEmpty() && 조건` 순서(short-circuit)로 방어해야 함을 지적 후 즉시 이해·적용. 스택/큐 계열 문제에서 계속 관찰 필요.
- **백트래킹 시 방문 배열(visit) 초기화 위치 오류 (Day129):** 재귀 함수 내부에서 매번 재생성하면 상태가 소실됨을 지적 후 정확히 이해.
- **원본 문자열 vs split 결과 배열 인덱싱 혼동 (Day 128):** 새 변수를 만든 시점에 "이제부터는 이 변수만 써야 한다"를 의식적으로 표시하는 습관 필요.
- **Map 조회 API 선택 혼동 (Day 128):** `get`/`getOrDefault`/`computeIfAbsent` 차이. "이 Key가 항상 존재를 보장받는가?"를 먼저 판단하고 API를 고르는 습관 필요.
- **그래프형 배열 크기 설계 실수 (관찰 지속):** 최근 세션들에 그래프형 배열 크기 문제가 없어 재발 여부 확인 불가. 다음 그래프 문제에서 계속 관찰.
